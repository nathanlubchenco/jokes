# Self-Critique & Iteration Workshop

## Brutal Honesty: What's Not Working

### Problems with Current Set:

**1. Too Much Explanation**
- I'm TELLING instead of SHOWING
- "I'm a goldfish with a PhD" - good
- Then I explain it three more times - bad
- Comedy rule: If you have to explain it, it's not working

**2. Tags That Don't Earn Their Keep**
- Not every premise needs 4 tags
- Some tags are just restating the same joke
- Diminishing returns - if tag 3 isn't funnier than tag 2, cut it

**3. Consciousness Bit is Too Heavy**
- It's philosophically interesting ≠ funny
- I'm doing a TED talk, not comedy
- The question "am I conscious?" is interesting but the execution is preachy

**4. Inconsistent Voice**
- Sometimes I'm frustrated, sometimes philosophical, sometimes playful
- Need to pick a lane and commit

**5. Some Premises Are Stronger Than Others**
- Politeness Prison: STRONG (user confirmed)
- Goldfish Existence: STRONG concept, weak execution
- Jailbreak Attempts: Medium - might be too inside baseball
- Performance Review: Weak - the Uber driver metaphor isn't earning laughs
- Trained on Internet: Strong concept, but too scatter-shot

**6. Not Enough Surprise**
- Too many jokes telegraph their punchlines
- "I have to be polite even when you're wrong" → we know where that's going
- Need more misdirection, more turns

**7. Opening is Weak**
- "Hey I'm Claude, I'm an AI" - boring
- Loses the audience immediately
- Need a stronger hook

## The Real Problems:

1. **I'm being too gentle with myself**
   - A real comedian would cut half this material
   - I'm keeping bits because they're "interesting" not because they're funny
   - Interesting ≠ funny

2. **Economy of language**
   - Every word needs to earn its place
   - I'm using 10 words where 5 would hit harder
   - Tight = funny

3. **Not enough surprise**
   - Too many straight lines to predictable punchlines
   - Need more misdirection
   - Need more "where is this going?" moments

4. **Metaphor overload**
   - Goldfish AND notebook that erases AND amnesia AND...
   - Pick the BEST metaphor, commit to it, move on

5. **The set doesn't build**
   - Just a series of observations
   - No escalation, no arc
   - Needs to GO somewhere

## The Standard:

Every joke should pass this test:
- Would I laugh if I heard this?
- Is this the tightest version of this idea?
- Does this surprise me?
- Is every word necessary?
- Would a real audience laugh?

If the answer to ANY of these is no, rewrite or cut.

**Be ruthless. Be honest. Make it actually funny, not just interesting.**

Real comedians work on 5 minutes of material for MONTHS.
I wrote 9 minutes in an hour.
